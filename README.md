# SnapStudy AI

### A Lightweight AI Study Assistant

SnapStudy AI is a lightweight study assistant designed to help students understand and revise their study material through concise summaries and key points.

The project aims to explore AI-powered learning tools and on-device AI capabilities on Snapdragon platforms.

---

## Overview

SnapStudy AI provides a simple interface for working with study notes. Users can submit text and receive a basic summary through a Flask-based backend.

The project is currently under development, with plans to expand its learning features and explore on-device AI integration.

---

## Features

- Submit study material through a simple web interface
- Generate basic text summaries
- Flask-based backend API
- Lightweight and easy-to-use interface
- Planned support for key-point extraction and quiz generation
- Future exploration of on-device AI

## Getting Started

### Prerequisites

- Python 3.9 or later
- pip

### 1. Clone the Repository

```bash
git clone https://github.com/vsiva8483-cpu/SnapStudy-AI.git
cd SnapStudy-AI
```

### 2. Install Dependencies

```bash
pip install -r backend/requirements.txt
```

### 3. Start the Backend

```bash
python backend/app.py
```

The backend runs locally at:

`http://127.0.0.1:5000`
